IP-TRX-CTRL

Remote control of an HF radio over the internet: two-way 8 kHz audio with AES-256 encryption, CAT control with Hamlib or TCI (also the radio audio via TCI, with no sound cards or cables), PTT (CAT, RTS, DTR, VOX, TCI), keyer with WAV messages in SSB and text macros in CW, CW waterfall and decoder, VFO B with split, TX power, access also from the browser of a phone, tablet or PC without installing anything (from 0.3.1), SWR protection (warning and transmit lock), maximum transmit time, priority to whoever is at the radio, listen-only clients, radio controls (NR, NB, Notch, ATT, preamplifier, AGC, compressor, squelch, ALC), bands, step and memories, the radio's panadapter (Icom via CI-V, SDR via TCI), mute of the server's sound cards. On the client: digital-mode programs (WSJT-X, JTDX, fldigi…) with a local rigctld and virtual audio cables, PTT pedal and mechanical CW key on a serial port. Ports opened with UPnP and checked from outside, reverse connection and audio over UDP when possible.

Since 0.3.6: Opus audio between two programs, several listen-only clients while one operator transmits, USB and MIDI CW key (VBand, Vail) with iambic keyer also in the web page, QSO log sent to GridTracker, JTAlert and Log4OM with the WSJT-X UDP protocol and ADIF export for LoTW, networked Icom radios (IC-7610, IC-9700, IC-705…) with no PC next to the radio, like wfview. Licence: GNU AGPL 3.0 or later.

Since 0.3.7, with the best solutions of other remote-control projects: HamNoise neural noise reduction for voice and CW, VOX turned on with a button next to PTT, voice squelch, notes between operator and listeners, listeners also hear the transmitting operator, QSO audio recording, direct IPv6 connection with ports opened by PCP, server without a window (systemd service for a headless Raspberry Pi) and WinKeyer emulation for N1MM, DXLog, TR4W, Win-Test and QLog. See New in 0.3.7.

One program for both PCs: server (the radio is connected here) and client (the operator). The roles are chosen at the first start and can be swapped.

Versions: Windows 10/11 64 and 32 bit and ARM, Windows 7 SP1, 8 and 8.1 (64 and 32 bit), Linux (Debian and derivatives, Fedora, openSUSE, Arch, Slackware, Alpine, AppImage for all), Raspberry Pi 64 and 32 bit, macOS Apple Silicon and Intel.

Automatic updates

From 0.3.2 the program updates itself. At start-up and then every 6 hours it checks the latest version published here on GitHub; if it is newer, it downloads the right package for the PC, checks its size and SHA-256 fingerprint and restarts in the new version. It does so only when no session is running and nobody is transmitting: if a session is open, the new version stays ready and is installed as soon as it ends. A server left on updates and restarts by itself, with the same settings. Settings, keys, pairings and logs are not touched.

These update themselves: the Windows installer and portable zip, the portable tar.gz (Linux, Raspberry Pi, Alpine), the AppImage, IP-TRX-CTRL.app on the Mac (moved to Applications or another folder the user can write to).

The system package managers' packages do not update themselves: .deb (Debian, Ubuntu, Mint, Raspberry Pi OS), .rpm (Fedora, openSUSE), Arch and Slackware. They are installed by root in /opt and belong to the package manager: the program only shows the new-version warning, and you install it with the same command as the first time. If you want automatic updates, use the AppImage or the portable tar.gz.

They can be switched off in Settings › Main window («Automatic updates» checkbox): the warning stays, with the «Update now» button. 0.3.0 and 0.3.1 don't update themselves: install 0.3.2 by hand once, and the following ones arrive by themselves. New versions of the same protocol talk to the previous ones; if one day the protocol changes, the two PCs align themselves at the first check (at start-up or within 6 hours).

You can also use the browser without installing anything (from 0.3.1): see docs/Accesso-dal-browser.md.

Errors and logs

The program writes errors to errori.log and the connection log to sessioni.log, in the data folder:

  • Windows: %APPDATA%\IP-TRX-CTRL (Win+R, type the path and press Enter)
  • Linux and Raspberry Pi: ~/.config/IP-TRX-CTRL
  • macOS: ~/.config/IP-TRX-CTRL

From the program: Settings › Open data folder. To report a problem, open an Issue and attach errori.log (and sessioni.log for connection problems). Details in docs/Registri-e-risoluzione-problemi.md.

The documentation is in the docs folder. The licence notes of third-party components are in THIRD-PARTY-NOTICES.txt and in the program's «About and licences» window.

Declared use: amateur radio activity.
