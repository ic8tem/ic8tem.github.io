YAEC – Yet Another EME Calc

by Costantino IC8TEM

Moon position, pointing windows, EME link budget, sky and solar noise calculator for radio amateurs, in 37 languages. Windows, Linux and macOS (Linux and macOS with Mono).

Automatic updates — from 1.9.1: at start-up YAEC checks GitHub for a new version and updates itself with the Windows installer or zip, the portable .tar.gz archives (Linux, Raspberry Pi, FreeBSD, OpenBSD, Alpine), the AppImage and the macOS app; every package is checked against SHA256SUMS.txt. The .deb, .rpm, Arch (.pkg.tar.zst) and Slackware (.txz) packages are updated with the system package manager instead: YAEC announces the new version and opens the GitHub page.

  • Windows – download YAEC-x.y-windows-x64-setup.exe and run it. It installs YAEC into Documents\YAEC without administrator rights, with Start menu and desktop shortcuts and an uninstaller. If SmartScreen warns you: More info → Run anyway. No installation wanted? Extract YAEC-x.y-windows-x64-portatile.zip into a folder where you can write and run YAEC.exe.
  • Linux – Debian, Ubuntu, Mint – download yaec_x.y_amd64.deb and run sudo apt install ./yaec_x.y_amd64.deb (Mono is installed too); start YAEC from the applications menu or with yaec.
  • Windows 32-bit – YAEC-x.y-windows-x86-setup.exe or YAEC-x.y-windows-x86-portatile.zip.
  • Raspberry Pi (Raspberry Pi OS 64-bit, Pi 4/5) – download yaec_x.y_arm64.deb and run sudo apt install ./yaec_x.y_arm64.deb.
  • Linux – other distributions – install Mono (sudo dnf install mono-complete, sudo pacman -S mono, sudo zypper install mono-complete), extract YAEC-x.y-linux-x64.tar.gz (ARM: YAEC-x.y-linux-arm64.tar.gz, YAEC-x.y-linux-armv7l.tar.gz; Linux i686: YAEC-x.y-linux-x86.tar.gz; FreeBSD amd64: YAEC-x.y-freebsd-x64.tar.gz; OpenBSD amd64: YAEC-x.y-openbsd-x64.tar.gz) and run ./install.sh.
  • macOS (experimental) – install Mono for macOS and XQuartz, open YAEC-x.y-mac-apple-silicon.dmg (Apple Silicon) / YAEC-x.y-mac-intel.dmg (Intel) and drag YAEC into Applications; the first time, right-click → Open.
  • Every release has SHA256SUMS.txt to check the downloaded files.

Features


Live position and +- 24h
EME budget Yagi
Distance and Dgrd

YAEC puts in one program everything you need to run an EME (Earth–Moon–Earth) station on 50, 70, 144, 222, 432 and 902 MHz and 23 cm (1296 MHz), especially when the station has limits: an antenna without elevation, a rotator with limited travel, obstacles that hide part of the sky. It tells you not only where the Moon is, but whether your antenna can really reach it, when, and under which conditions. The bands above 432 MHz are still being completed, but the DGRD is already computed correctly at every frequency; more advice for newcomers above 900 MHz will follow.

Live - Live position and +- 24h – main screen updated every second: your locator and the DX's (4 to 14 characters), frequency, UTC, local and DX clocks, a status band (pointable, outside the limits, below the horizon, common window) with countdown, compass and elevation arc. Typing the DX callsign fills in its locator from CALL3.TXT. - Reconnaissance of my obstacles – aerial or topographic map centred on your station with the sky drawn on it: Moon position, its path over the next 24 hours, rise and set, antenna limits that you drag with the mouse. - My horizon – Horizon from terrain: panorama of the terrain around your station from SRTM1 elevation data (about 30 m), with Earth curvature and refraction, over the sky view (three colour scales) or a light-blue sky; Moon path, rise and set above the terrain, main obstacles named from OpenStreetMap and minutes of Moon lost. One checkbox makes the terrain the minimum elevation in the whole program. Local noise map (NJ9R): azimuth × elevation grid where you type the noise seen in WSJT-X while turning the antenna; the hours with the Moon in a noisy direction get a ⚠. - Sky view – the sky seen from your QTH with the sky-noise colours at your frequency, antenna limits, the DX horizon, radio sources, the Sun and the Moon path.

Planning - Distance and Dgrd – 7 to 61 days of Dgrd and mean Moon distance, with the declination overlaid, perigee, apogee, new Moon, the three best days (in date order), a possible fourth useful day and a warning for the days when the Moon is close to the Sun. Only the hours in which the Moon is really pointable with your limits are counted. - DGRD by frequency – the Dgrd at your working frequency with the real noise of your station and the sky averaged over the antenna beam, compared with the usual WSJT-X calculation; the choice applies to the whole program. - Sky noise (Skynoise) – Antenna temperature computed with the Skynoise method (G8ONH, G4SWX): the full antenna pattern (NEC .out file, YA-NEC file or Gaussian beam of the EME budget) is pointed at the Moon and each direction reads the sky map at the chosen band (Remazeilles, Haslam, GSM 2008 or LFmap); below the horizon it is 290 K or the terrain of My horizon. It shows the map with the Moon path over the month (click a day for its pass), the antenna temperature during the pass for you and for the DX, the sky behind the Moon, the check average gain, the effect on the EME budget Yagi and the comparison with the Gaussian beam and with the DJ9BV method. - Stations to try – for the chosen day, the stations active in the N0UK EME chat (144 MHz) with a common window with you, the best per locator field, ranked by an index from 0 to 100 from the S/N in both directions; the DX setup is read from what it writes in the chat. A rough example calculation, idea by Matteo IW5DHN. - Moon position – table for the chosen period, coloured by pointability, with the common windows for you and the DX; CSV export for Excel. - Moon over the world – world map coloured by the Moon elevation seen from every place; one click makes that point the DX.

Link - EME budget Yagi – link budget for every band, stored band by band: six indicators (link possible, my EIRP, DX EIRP, path loss, S/N me → DX and DX → me, also with the Sun and in 2500 Hz), the full table of steps and an interactive diagram of the station (antenna, cables, relay, preamplifier, transverter, radio). Ground gain for antennas without elevation. Modes with a 60 s period: JT65, Q65-60A, Q65-60B, Q65-60C and custom. Echo mode (I transmit and receive my own echo): echo level, delay and Doppler. - EME budget dishes – the same budget, echo included, for dish antennas at 432, 902 and 1296 MHz, prime focus or offset (W2IMU): gain with the PE1RKI formula, beamwidth 70·λ/D, single- or two-stage preamplifier, transverter and PA drive; on 23 cm, circular polarization with 0.4 dB of loss (KA1GT). - GRAVES radar – the French GRAVES radar (143.050 MHz) as a test bench: when the Moon is in its beam and within your antenna limits, with Doppler and echo delay. - Solar noise – downloads the solar fluxes measured by the RSTN network (NOAA) and estimates how much the Sun raises the receiver noise near new Moon. - Export calculations to Excel and Calculation check – the budget as an Excel sheet, and every formula with the substituted values, step by step, for the Yagi or the dish budget.

Log, help and tools - WWL map and ADIF – Maidenhead grid with worked and confirmed squares from your ADIF file or downloaded directly from LoTW, also by band and EME only. - USER MANUAL and THEORY AND TIPS ON EME – full manuals inside the program in every language, with clickable index, search, formulas and sources; exportable to Word. The theory manual includes the advice of experienced EME operators, a section on internet chats and the VE7BQH antenna tables. - COAXIAL CABLES – database of 50 Ω cables with attenuation from 50 to 1296 MHz (data-sheet values and the formula α = k1·√f + k2·f) and the source of every value; sortable, filterable, with a loss calculator and a button that sends the cable to the EME budget. You can add your own cables.

Also - CALL3.TXT downloaded from W7GJ and WSJT-X Improved, merged, refreshed every 7 days and copied into WSJT-X on request. - Warnings for polar-cap and auroral absorption (PCA) when a station is beyond the polar circles or in the auroral zone. - 37 languages; light, night (blue), black and eight pastel and three IP-TRX-CTRL (blue, violet, green) colour schemes. - Moon positions accurate to about 0.01° (Meeus, ELP-2000/82), all calculations on your computer; data in a single data folder.

For developers

You do not need to compile anything to use YAEC: the installer and the packages above are built automatically. If you want to build it yourself on Windows, compila.bat compiles YAEC.cs with the C# compiler included in Windows (.NET Framework 4, C# 5). Every push is compiled by GitHub Actions on Windows and started on Linux with Mono; when the VERSION file on main holds a new version, the workflow publishes the release with the Windows installer (Inno Setup) and the Linux and macOS packages (.github/workflows/build.yml).
