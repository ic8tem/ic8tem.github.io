Windows
10/11 de 64 y 32 bits, Windows en ARM (PC Snapdragon) y también Windows 7 SP1, 8 y 8.1

Linux
Debian, Ubuntu, Mint (.deb), Fedora y openSUSE (.rpm), Arch y Manjaro, Slackware, Alpine, AppImage para cualquier distribución
